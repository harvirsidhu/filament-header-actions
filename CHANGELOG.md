# Changelog

All notable changes to `filament-header-actions` will be documented in this file.

## 1.0.0 - 202X-XX-XX

- initial release

## 1.1.0 - 2026-02-20

- Added `HeaderActionsComposer` for deterministic primary and overflow header action composition.
- Added configurable More menu presentation (label, icon, color, hidden label) via fluent API and package config.
- Added Filament 4 and 5 compatibility constraints with a compatibility helper for guarded APIs.
- Added Pest coverage for no-overflow, single-overflow flattening, multi-overflow grouping, and configurable presentation.
